- **Stage:** B1 P1
- **Report date:** 2026-09-04
- **Implementation revision:** `47ac2ecd27a4278aee7bda34a63ab108d4719e65`
- **Evaluation scale:** three seeds, 15 experimental conditions, 5,000 COCO `val2017` images

## Stage question

With the detector architecture, class split, training budget, and evaluation protocol fixed, does the real text condition produce a stable end-to-end detection benefit over deterministic-random expert selection across seeds? On the same trained model state, does changing the text condition change the model output and detection quality?

## Experimental setup

To help readers understand the report, terms are defined where they first appear. The experiment follows the fixed COCO 48/17 open-vocabulary protocol from P0, the preceding baseline stage. “Open-vocabulary” means that the model uses text class information to evaluate classes that did not appear directly during training; COCO `val2017` is the validation split of the general COCO object-detection dataset, and this report uses its 5,000 images.

The evaluated model is a detector, or object-detection model, that outputs object locations and classes for each image. The 65 evaluation classes are divided into 48 training-visible classes (Base48) and 17 training-unseen classes (New17); this report focuses on New17. All images use the same 65-class vocabulary, original COCO category IDs, and fixed object-detection evaluation procedure.

Training uses three seeds (`0/1/2`) and three conditions:

- **true-text:** a real text condition selected by a predefined selection table;
- **deterministic-random:** a deterministic random assignment;
- **fixed-balanced:** a fixed, approximately balanced assignment.

Here, a condition is the input provided to the text-conditioned router, and an assignment is the expert ultimately selected for each sample. `deterministic-random` is a random selection generated by a fixed rule; `fixed-balanced` is a fixed and approximately balanced selection; `true-text` is a real text condition related to the target class; `zero` is an input with the same shape and data type whose values are all zero; and `wrong-new` is a New-class text condition that does not match the target class.

Each condition uses the same training budget: a two-expert adapter is trained for 256 steps. The adapter is a trainable module inserted into the detector, and an expert is a model branch that processes features. After training, the model state for the `true-text` condition is evaluated with the intended real text (`true-new17`), an all-zero text condition (`zero`), and a wrong New-class text condition (`wrong-new`), producing 15 experimental conditions in total.

A seed is the index controlling random initialization and stochastic processes; the three seeds show how the results vary with initialization.

## Results

### Primary comparison: true text versus deterministic-random across seeds

This stage asks whether the direction of the real-text result relative to deterministic-random remains consistent across seeds. AP is the detection-quality metric averaged over IoU thresholds from 0.50 to 0.95, where IoU is the overlap between a predicted box and a ground-truth box; AP is reported on a 0–1 scale, with higher values indicating better detection quality. AP50 is computed only at IoU 0.50. All difference columns use AP points, meaning the AP difference multiplied by 100; for example, `+0.296` AP points means an AP increase of `0.00296`. Complete values, AP50, and resampling statistics are available in the [machine-readable results table](b1_p1_attribution_closure_results.csv).

To make cross-seed stability easy to read, Figure 1 sets the deterministic-random assignment to 0 within each seed and shows every condition’s relative position in three panels sharing the same horizontal scale. The large red circles mark the `true-text` primary comparison, the small gray circles provide same-scale context, and the dark diamonds mark the baseline. Across the shared AP-point axis, a point to the right of the zero line is above the baseline and a point to the left is below it; changes along the same row show variation across seeds.

![New17 AP relative-difference dot plot for each seed against the deterministic-random baseline](figures/b1_p1_attribution_closure_ap.svg)

The real-text result is higher for one seed and lower for the other two; the direction is therefore inconsistent across seeds, and the mean difference is negative. Under the fixed settings of this stage, no stable real-text detection advantage is observed.

In contrast, the real-text versus deterministic-random comparison changes both the training condition and expert selection, so it represents an overall difference rather than a text-input-only effect.

### Expert usage during training and inference

All nine training conditions completed 256 steps; both experts received training signal and their parameters were updated. “Selected proportion” is the frequency with which hard Top-1 assignment, meaning selection of the single highest-scoring expert for each sample, selects each expert. Expert 0 and Expert 1 are simply the two expert-branch identifiers.

| Random seed | Expert 0 selected proportion | Expert 1 selected proportion |
| --- | ---: | ---: |
| 0 | 99.960% | 0.040% |
| 1 | 0.140% | 99.860% |
| 2 | 0.000% | 100.000% |

Both experts receive learning signal during training, while inference for each seed is almost entirely dominated by one expert.

## Stage conclusion

P1 answers whether text-conditioned routing reaches the detector result path and whether that influence forms a stable detection benefit. The results show that text conditions can change routing-related outputs and produce measurable but small quality changes on the same checkpoint; real text versus deterministic-random does not form a stable New17 AP advantage across the three seeds. The current stage therefore observes a real text-condition signal that has not become a stable detection benefit.
